# agent_ai_intg — notes for Claude Code

Instagram Studio for Euro Digital (separate from the e-commerce project in `../euro-digital web e-commerce` and
`../euroDigital`, which this project only reads through the public catalogue API — never edit them from here).

- Skills: the 13 `/ig-*` skills in `.claude/skills` are project-local copies of `vendor/instagram-agent-skill`. Do not edit
  them; change upstream and run `npm run skills:install`. Their data folder is `.claude/instagram/` (voice.md lives there).
- Never invent prices, stock, warranty, discounts, delivery terms, specifications, reviews or figures. Use `{{to confirm}}`.
- Never publish, schedule live posts or call the Meta API with real credentials without the owner's explicit approval.
  `PUBLISHING_MODE` stays `disabled` in development.
- Secrets only in `.env.local` / the host's secret manager; never print them, commit them or put them in docs.
- Checks: `npm run verify` (typecheck, lint, tests) and `npm run build`. Tests use PGlite and mocked Meta/Claude.
